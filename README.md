# Theuščina pirátská hra

Kooperativní pirátská hra pro rodinu. Piráti jdou po ostrově k truhle
s pokladem a za nimi pluje kraken. **Vyhrávají všichni, nebo nikdo.**

## Jak se hraje

Hraje se u stolu: **hází se skutečnou kostkou** a na obrazovce se klikne,
co padlo. Na tahu si každý vybere — buď **pomůže kartou**, nebo **běží**.

- **Provaz:** nikdo se nesmí dostat víc než šest polí před nejzadnějšího.
  Kroky navíc se pošlou dozadu, takže rychlý hod vpředu táhne kamaráda.
- **Chapadla** vystřelí z laguny a stáhnou piráta ke krakenovi.
- **Sud prachu** se položí na cestu jako past. Kdo má pistoli, může ho
  odpálit přes celou mapu — nebo na něj kraken sám šlápne.
- Kdo dojde k truhle, **táhne za lano** a pomáhá posledním.

Prohrává se, když kraken dojde k truhle dřív než celá posádka.

## Spuštění

Otevři `index.html` v prohlížeči. Žádná instalace, žádné závislosti,
funguje i offline.

Jde o rozdělanou verzi v4, obtížnost je laděná simulacemi na zhruba
**75 % výher** pro čtyřčlennou posádku.
